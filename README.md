# LUMINA — ルミナス風 WEBパズル

ブラウザだけで遊べる、[Lumines（ルミナス）](https://luminesremastered.com/ja/) 風のパズルゲームです。
**ビルド不要・依存なし** — `index.html` を開くだけで遊べます。

## 遊び方

1. 2色の **2×2 ブロック** が上から落ちてきます。
2. 同じ色を **2×2 の正方形** にそろえると「消去待ち」になります（白い枠が付きます）。
3. 左から右へ流れる **タイムライン**（青い光の線）が通過した列で、消去待ちのセルが消えます。
4. 消えた後、上のセルは下へ落ちます。連鎖でさらに消えることも。
5. ブロックが最上段まで積み上がると **ゲームオーバー**。

## 操作方法（キーボード）

| キー | 動作 |
|------|------|
| `←` `→` | 左右に移動 |
| `↑` | 回転 |
| `↓` | 高速落下 |
| `Space` | 一気に落とす（ハードドロップ） |
| `R` | リスタート |
| `P` | 一時停止 / 再開 |

## スコア

- タイムライン通過で消したセル数 × コンボ倍率で加点
- 1回の通過で **3セル以上** 消すとボーナス
- 連続スイープで消し続けると **コンボ** が伸びて倍率アップ

## 起動方法

ファイルをダブルクリックして開くだけ：

```
index.html をブラウザで開く
```

ローカルサーバーで動かす場合：

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
