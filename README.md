# LUMINA ARISE — ルミナス風 音と光のパズル

ブラウザだけで遊べる、[Lumines / ルミネス アライズ](https://luminesremastered.com/ja/) 風のパズルゲームです。
**ビルド不要・依存なし** — `index.html` を開くだけで、音楽・エフェクト付きで遊べます。

> 音楽はすべて Web Audio API による**オリジナル合成**です（本家楽曲は使用していません）。
> 「操作が音楽になる」というルミネスの体験を、著作権フリーで再現しています。

## 特徴

- **24小節・3セクション構成のBGM** — A（イントロ）→ B（ビルド）→ C（ドロップ）で楽器・音量・フィルターが展開する抑揚のある楽曲。12コード（Am F C G / Dm Am E Am / F C Dm E）で進行し、セクション頭のクラッシュ、ドロップ前のライザー、折返し前のスネアフィルで盛り上げます
- **エジプト音階のリード** — 情景に合わせ、リード旋律は A フリジアン・ドミナント（エジプト音階）で異国情緒
- **多層シンセ＋空間系** — スーパーソー・パッド／プラック・アルペジオ／サブ＋ミッドベース／デチューン・リードに、合成IRリバーブ＋付点8分ディレイとキック連動サイドチェイン。タイムラインはBPMに同期し、消したブロックがFMベルの旋律を奏でます（列位置でステレオパン）
- **ダイナミックミュージック** — コンボや盤面の高さでもレイヤーが増減
- **BURST** — 消去でたまるゲージが満タンになると `Enter` で発動。大量消去＋全画面エフェクトでピンチを打開
- **COMBO / BONUS** — 連続スイープで倍率（×2・×4・×8・×16）アップ
- **エジプト／ピラミッドの背景** — 藍→紫→マゼンタ→橙→黄金へと移ろう砂漠の夕焼けグラデーション、光線を放つ太陽、光と影で立体化したギザ風ピラミッド群（遠景は霞む）、砂丘、瞬く星、漂う砂塵、拍ごとに広がる陽炎リング
- **リッチな演出** — ガラス質の宝石ブロック、着地予測ゴースト、尾を引くタイムライン、砕け散る破片＋光柱の消去演出、ピンチ時の赤ビネット
- **HUD** — SCORE / 2×2 SQUARES / TIME / COMBO / BURSTメーター / NEXT

## 遊び方

1. 2色の **2×2 ブロック** が上から落ちてきます
2. 同じ色を **2×2 の正方形** にそろえると「消去待ち」に（白い枠が光ります）
3. 左から右へ流れる **タイムライン** が通過した列で、消去待ちのセルが消えます
4. 連続で消すほど **COMBO** が伸び、スコア倍率アップ
5. BURSTゲージ満タンで `Enter` → **大量消去**
6. ブロックが最上段まで積み上がると **ゲームオーバー**

## 操作方法（キーボード）

| キー | 動作 |
|------|------|
| `←` `→` | 左右に移動 |
| `↑` | 回転 |
| `↓` | 高速落下 |
| `Space` | 一気に落とす（ハードドロップ） |
| `Enter` | BURST（ゲージ満タン時） |
| `P` | 一時停止 / 再開 |
| `R` | リスタート |
| `M` | ミュート切り替え |

## 起動方法

`index.html` をブラウザで開くだけ（音を鳴らすため、最初に **START ボタン**または `Space` を押してください。ブラウザの自動再生制限のため、最初の操作が必要です）。

ローカルサーバーで動かす場合：

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 実装メモ

- タイムラインは音楽のBPM（8分音符ごとに1列）に同期。マークは「通過するまで保持」される本家準拠の挙動で、2×2スクエアが確実に消えます。
- 音声はユーザー操作後に `AudioContext` を起動（ブラウザの自動再生ポリシー対応）。
- `window.LUMINA` に自動テスト用のフックがあります（通常プレイには影響しません）。
