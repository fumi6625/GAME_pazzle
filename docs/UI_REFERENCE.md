# 画面レイアウトの目標（ルミネス リマスター / モバイル版）

作者から提供された実機スクリーンショット5枚（スキン違い）を読み取って
文章に起こしたものです。**この文書が UI の正解**で、
`tools/uicheck.py` と比較用エージェントはこれを判定基準にします。

横持ち前提。縦横比はおよそ 2.18:1（1568×720 / 2000×919）。

---

## 1. 全体

- 背景はスキンの絵が**画面いっぱい**に出る。黒帯は無い。
- UI は背景の上に浮かぶ。パネルは半透明で、背景の絵が透けて見える。
- 3列構成。**左レール / 中央（盤面） / 右レール**。

```
┌─────────────────────────────────────────────────────────────┐
│                      NEXT                            [II]   │  ← 一時停止は右上
│  ┌──┐   ◆ ◆ ◆ ◆ ◀[NEXT]▶ ◆ ◆ ◆ ◆                    LEVEL   │
│  │2nd│  1─2─3─4─5─6─[7]▶                              1     │
│  └──┘  ┌───────────────────────────┐                 TIME   │
│  ┌──┐  │                           │                 4:08   │
│  │3rd│ 5│        盤面 16x10        │5                SCORE  │
│  └──┘  │                           │                 1,044  │
│  ┌──┐  │                           │                HI-SCORE│
│  │4th│  └───────────────────────────┘                5,972  │
│  └──┘                                                ERASED │
│  ‹  ›       （床の反射）                               41    │
│  (mascot)                        ♪ Shinin' / Mondo Grosso   │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 盤面（中央）

| 項目 | 値 |
|---|---|
| 左端 | 画面幅の **25〜26%** |
| 右端 | 画面幅の **74〜75%** |
| 上端 | 画面高の **27%** |
| 下端 | 画面高の **90〜91%** |
| マス | 16列 × 10行。セルはほぼ正方形 |

- 枠は**左・右・下だけ**に細い白線（1px）。**上は開いている**。
- 左右の枠の、上から5行目の位置に小さく `5` の目盛り。
- 内部のグリッドはスキンの色（赤／白／灰）で細線。交点に小さな点。
- 盤面の中は半透明で、背景の絵がはっきり透ける。

---

## 3. 盤面の上（中央上）

上から順に:

1. **`NEXT` の文字**（白・小さめ・字間広め）。盤面の中央より少し右、
   次のコマの真上。
2. **次のコマ**が白い枠に囲まれて置かれる。盤面の上端に接している。
   枠の左右に `◀` `▶` の小さな三角。
3. **ひし形マーカーの列**（`◆`）。盤面の幅いっぱいに等間隔。スキンの色。
4. **順番ストリップ** `1─2─3─4─5─6─7─8`。小さな四角に数字、間はダッシュ。
   現在位置は**黄色い枠**で囲われ、右に黄色い `▶`。
   盤面の左端から始まり、右へ伸びる。

---

## 4. 左レール

- 上から **次の次以降のコマを3つ**、2x2 のまま縦に並べる。
  スキンによっては `2nd` `3rd` `4th` のラベルが左に付く。
- その下に **半透明の丸いマスコット**（大きめ・目のあるキャラ）。
- 中段に **大きな半透明の `‹` `›` 矢印**。左右移動の操作。
- 幅は画面幅のおよそ **8〜13%**。

---

## 5. 右レール

- 上から **LEVEL / TIME / SCORE / HI-SCORE / ERASED**。
- 各項目は「**ラベルの帯**（角丸または矩形の半透明パネル）」＋
  「**その下に大きな数字**」の2段組。数字は右寄せ。
- 数字は角ばったテクノ系の書体、桁区切りのカンマあり。
- HI-SCORE の行に**丸いリスタートのアイコン**が重なる。
- ERASED の上に **`⌄` の下向きシェブロン**。
- 幅は画面幅のおよそ **13〜16%**。

---

## 6. 操作ボタン（この作品での配置）

参考画面には無いが、本作はタッチ操作なので次のように置く。
**作者の指示: バーストは右側の回転ボタンの「上」。**

- 左レール … `‹` `›`（左右移動）
- 右レール下部 … 上から **BURST A / BURST B** → **↺ / ↻（回転）** → **⤓（即落下）**
- 右上 … 一時停止 `II` とミュート `♪`

---

## 7. ブロックのデザイン

- 正方形のタイル。**外周に明るい1〜2pxの縁**。
- 面はわずかに立体的（上が明るく下が暗いベベル）。
- 中央に**一回り小さい四角**（チップ）。スキンによっては中に4つの点。
- 1スキンにつき2色。例: オレンジ/灰、シアン/黄、黒/白、シアン/マゼンタ。
- 消去待ちのマスは**べた塗りの明るい色**になり、
  中央に**消える個数の数字**が出る。

---

## 8. その他

- 盤面の下に **床の反射**（ブロックが鏡像で映り、奥へ遠近が付く帯）。
- 右下に **`♪ 曲名 / アーティスト`**（白のイタリック）。
- タイムラインは**明るい縦の帯**で、後ろに広い色の尾を引く。
  通過中の列は帯の色で塗られる。

---

## 9. 判定に使うチェック項目

`tools/uicheck.py` が数値で見るもの:

| # | 項目 | 合格条件 |
|---|---|---|
| 1 | 盤面の左端 | 画面幅の 23〜29% |
| 2 | 盤面の右端 | 画面幅の 70〜78%（※） |
| 3 | 盤面の上端 | 画面高の 23〜31% |
| 4 | 盤面の下端 | 画面高の 87〜94% |
| 5 | セルの縦横比 | 0.9〜1.1（ほぼ正方形） |
| 6 | 左レールの幅 | 画面幅の 7〜15% |
| 7 | 右レールの幅 | 画面幅の 12〜18% |
| 8 | 左レールに次コマ3つ | 3つ表示されている |
| 9 | 右レールの項目 | LEVEL / TIME / SCORE / HI-SCORE / ERASED の5つ |
| 10 | BURST の位置 | 回転ボタンより上（y が小さい） |
| 11 | 回転ボタンの位置 | 即落下ボタンより上 |
| 12 | 順番ストリップ | 盤面の上に存在し、現在位置が強調されている |
| 13 | 画面内 | どの要素も画面からはみ出さない |
| 14 | 背景 | 画面いっぱい（黒帯なし） |

※ 参考画面の実測（幅49% / 高さ63%）は、セルをきっちり正方形にすると両立しません。
本作はセルの正方形を優先しているので、盤面は参考より 1% ほど細くなります。

## 10. 指で押せる大きさ（`tools/touchcheck.py`）

レイアウトが似ていても、**実寸で押せなければ意味がありません**。
スクリーンショットの解像度（1568×720）は物理ピクセルであって
CSS ビューポートではなく、実機の横持ちは **667×375〜932×430 pt** しかありません。
この取り違えで、当初はすべてのボタンが指針の半分以下でした。

| 指針 | 値 |
|---|---|
| Apple HIG の最小 | 44×44 pt ≒ 7.0mm |
| Material Design の最小 | 48×48 dp |
| 指の接触面 | 人差し指 8〜10mm / 親指 10〜14mm |
| 本作の狙い | 短辺 **7mm 以上**、回転と移動は **9mm 以上** |

`python3 tools/touchcheck.py` が、実機4機種の CSS ビューポートと
画面の物理サイズから mm を出して判定します。
