# PRISM SHUFFLE — 音楽・操作音セット仕様

音楽連動パズルゲーム(ルミネス/テトリスエフェクト系)用の素材一式です。
**この仕様書は実装する側が読む前提で書いています。**

---

## 1. グリッド定数(実装で必要な数値)

| 項目 | 値 |
|---|---|
| テンポ | **135 BPM** |
| 1拍 | 0.444444 秒 |
| 1小節 | 1.777778 秒(4拍) |
| 16分音符 | 0.111111 秒 |
| ループ長 | **32小節 = 56.888889 秒**(サンプル数 2,508,800 @ 44.1kHz) |
| スウィング | 裏16分を **13.33 ms** 後ろへ(16分の12%) |
| 調 | **F ドリアン**(F G A♭ B♭ C D E♭) |
| 操作音の音階 | **F マイナーペンタトニック**(F A♭ B♭ C E♭) |

ループは**サンプル単位で正確に32小節**、継ぎ目のクリックなしを検証済みです。

### 操作音のクオンタイズ

プレイヤー入力を音楽グリッドに吸着させる場合:

```
16分グリッド: t_q = round(t / 0.111111) * 0.111111
スウィング適用: 奇数番目の16分は +0.01333 秒
```

ルミネス型の「タイムライン掃引」なら、1小節=1.777778秒で左端→右端を1周させ、
ブロック消去をその瞬間に合わせます。

## 2. 音楽ステム(`stems/`)

| ファイル | 内容 | 想定される投入タイミング |
|---|---|---|
| `01_drums.wav` | キック/クラップ/ハイハット/パーカッション | 常時 |
| `02_bass.wav` | ベース+サブベース | 常時 |
| `03_chords.wav` | コードスタブ+ローズ | レベル2〜 |
| `04_melody.wav` | メインフック | レベル3〜 |
| `05_atmos.wav` | パッド+高域のノイズ層 | 常時(後述) |

**全ステムが同じ32小節ループです。**同時再生すれば位相まで一致します。

**重要:** `sum(全ステム) × 1.083` が `PRISM_SHUFFLE_loop.wav` と完全一致します
(誤差 0.0002)。ステムには8%のヘッドルームを持たせてあるためです。
全部鳴らす場合はマスター側で +0.7 dB してください。

**`05_atmos` は常時鳴らすことを推奨します。**このステムには連続した高域ノイズ層が
入っており、ハイハットの刺さりを抑える役割を持っています。これを切ると高域が
むき出しになり、長時間プレイで耳が疲れます(実測で確認済みの現象です)。

### 段階的な盛り上げの例

```
静か  : 01 + 02 + 05
標準  : 01 + 02 + 03 + 05
高揚  : 01 + 02 + 03 + 04 + 05   (全部)
```

フェードは小節境界(1.777778秒の倍数)で、0.2〜0.4秒のクロスフェードを推奨します。

## 3. 操作音(`sfx/` 27種)

**全て F マイナーペンタトニック**です。半音も三全音も含まないため、
**プレイヤーがどのタイミングで何個同時に鳴らしても濁りません。**
音楽は F ドリアンですが、ペンタトニックはその部分集合なので衝突しません。

音域は **C5(MIDI 72)以上**に配置してあります。曲のメロディは意図的に
低め(中央値 MIDI 59 前後)に書いてあるので、操作音の居場所が空いています。

| ファイル | 音程 |
|---|---|
| `move_left` | C5 (72) |
| `move_right` | D#5 (75) |
| `rotate_cw` | F5 (77) |
| `rotate_ccw` | D#5 (75) |
| `soft_drop` | C5 (72) |
| `hard_drop` | C6 (84) |
| `lock` | C5 (72) |
| `invalid` | - |
| `clear_1` | G5 + C6 |
| `clear_2` | G5 + C6 + F6 |
| `clear_3` | G5 + C6 + F6 + A#6 |
| `clear_4` | G5 + C6 + F6 + A#6 + D#7 |
| `combo_01` | F5 (77) |
| `combo_02` | G5 (79) |
| `combo_03` | A#5 (82) |
| `combo_04` | C6 (84) |
| `combo_05` | D#6 (87) |
| `combo_06` | F6 (89) |
| `combo_07` | G6 (91) |
| `combo_08` | A#6 (94) |
| `combo_09` | C7 (96) |
| `combo_10` | D#7 (99) |
| `combo_11` | F7 (101) |
| `combo_12` | G7 (103) |
| `level_up` | C5 + F5 + A#5 + C6 + F6 |
| `stage_clear` | F4 + G#4 + C5 + D#5 + G5 + C6 |
| `game_over` | C5 下降スイープ |

### 連鎖(combo)の使い方

`combo_01` から `combo_12` は**ペンタトニックを1段ずつ上行**します。
連鎖数に応じて順に鳴らすと、そのまま上昇フレーズになります。
13連鎖以上は `combo_12` を繰り返すか、オクターブ上げてください。

### ライン消去

`clear_1` 〜 `clear_4` は消去ライン数に対応し、**多いほど和音が厚く高く**なります。

## 4. ミックスの実測値

参考にした市販曲11曲(ビッグビート)の平均と比較しています。

| 指標 | 本素材 | 参考曲平均 |
|---|---|---|
| クレストファクター | 12.3 dB | 11.4 dB |
| 高域ピーク | −5.5 dB | −5.0 dB |
| 高域 wash | 0.544 | 0.35 |
| air帯域 | −19.5 dB | −21.8 dB |

**wash を参考曲より高めに取ってあります。**これは高域エネルギーが
「むき出しの打点」ではなく「連続した層」として存在する度合いで、
長時間プレイでの聴き疲れを抑えるための意図的な設定です。

## 5. 再生成

`build.py` が全ソースです。以下を変えて再実行できます:

- `set_tempo(135, swing=0.12)` — テンポとスウィング
- `PROG` — コード進行(現在 Fm9 → A♭maj9 → B♭13 → E♭maj9)
- `HOOK` — メロディ `(小節, 16分位置, 長さ, MIDIノート)`
- `BARS = 32` — ループ長

必要: Python + numpy + scipy のみ。約6秒で全素材が再生成されます。
